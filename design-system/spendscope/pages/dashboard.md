# SpendScope dashboard overrides

The skill's generated master is a verified generic flat-fintech starting point. This personalized CSV analytics page uses the following overrides so it is distinct from other portfolio applications.

- Product is a spending CSV explorer; it does not split bills or balances.
- Paper canvas #f7f4ed; deep teal #174e48; coral accent #b84e37; ink #253b36; muted ink #5b6963.
- Editorial serif title with system Georgia fallback, sans-serif body with Arial fallback; no external font fetch.
- Flat bordered panels, compact table, large total emphasized above trend/category analyses, warm outlier panel and visible synthetic-source labeling.
- Desktop two-column chart/detail grids become stacked mobile layouts. Labeled native filters and file controls remain usable.
- Motion numbers/line/rows are purposeful data transitions with reduced-motion handling; no continuous decoration.
- Detailed feature-specific tokens/states/accessibility and source prompts are in `Design.md`.
